MediAssist: Fail-Closed Clinical AI Architecture

MediAssist is designed to strictly prevent generative LLM hallucinations. Instead of relying on a monolithic model to guess, it routes patient queries to isolated, authoritative medical databases—and closes the path to generation when confidence is insufficient.

01 / Overview

Generation is the final step—not the source of truth.

The system treats uncertainty as a routing failure rather than an invitation to improvise. Every query must pass classification, confidence, domain, and retrieval checks before a generative model can produce an answer.

01

Route each query to the appropriate clinical domain.

02

Retrieve from an isolated, authoritative offline index.

03

04

Reject the request when confidence or evidence is insufficient.

03 / Key methodologies

Four controls between a question and an answer.

01

Multi-Agent RAG

Orchestrates strict routing between specialized models and isolated medical knowledge domains instead of asking one monolithic model to answer everything.

02

Bayesian optimization

Uses Optuna’s Tree-structured Parzen Estimator to explore learning rates efficiently while controlling overfitting.

03

Multi-index hybrid search

Merges FAISS semantic results with BM25 exact matches through Reciprocal Rank Fusion, reducing exact-match dilution.

04

Confidence thresholding

Transforms router logits into probabilities with Softmax and rejects ambiguous queries before they can reach generation.
